# 흑성산자연휴양림 조성사업 웹 프레젠테이션

원본 PowerPoint 10장의 시각적 디자인과 모든 표시 정보를 보존한 **정적 웹 프레젠테이션**입니다.

## 로컬 실행

`index.html` 파일을 브라우저에서 열면 별도 서버 없이 실행됩니다. 이미지가 표시되지 않는 환경에서는 폴더 전체를 그대로 웹서버 또는 GitHub Pages에 올리세요.

## GitHub Pages 게시

1. GitHub에 새 저장소를 만듭니다.
2. 이 ZIP 파일을 압축 해제한 뒤, `index.html`과 `assets/` 폴더를 **같은 저장소 루트**에 업로드합니다.
3. 저장소의 **Settings → Pages → Build and deployment**에서 `Deploy from a branch`를 선택합니다.
4. `main` 브랜치, `/ (root)` 폴더를 선택하고 저장합니다.
5. GitHub Pages에서 제공하는 주소를 엽니다. 별도 빌드나 데이터베이스가 필요하지 않습니다.

## 조작법

- 이전/다음 버튼, 방향키, PageUp/PageDown, 스페이스바
- 마우스 휠, 모바일 터치 스와이프
- 목차/썸네일에서 임의 슬라이드로 이동
- 사진 위의 상호작용 영역을 누르면 설명 표시
- ⤢ 확대 보기 / ⛶ 발표 모드 / F 발표 모드 / O 목차 / Esc 닫기
- URL의 `#slide-5`처럼 슬라이드별 직접 링크

## 파일 설명

- `index.html`: HTML/CSS/JavaScript 전체(외부 라이브러리 불필요)
- `assets/slide-01.webp` ~ `slide-10.webp`: 원본 슬라이드 화면
- `assets/thumb-01.webp` ~ `thumb-10.webp`: 내비게이션 썸네일

**주의:** 건축·시설·공간배치 관련 이미지는 구상 예시이며, 공식 확정 설계/조감도를 나타내지 않습니다. 첫 장의 제공 사진은 사용자가 제공한 항공사진입니다. 슬라이드 본문은 화면 이미지로 원본을 보존하고 핵심 텍스트는 웹 설명 패널에서 접근할 수 있도록 제공했습니다.
